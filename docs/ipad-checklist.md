# iPad and phone checklist

Run through this once on each iPad (Gold Class and Candy Bar), and on one staff phone. It takes about 10 minutes.

## 1. Install the app

1. Open the app's address in **Safari** (not Chrome: only Safari can install it on an iPad or iPhone).
2. Wait for the home screen to load and show the three departments. Leave it open for about 10 seconds so the device saves everything it needs for offline use.
3. Tap **Share > Add to Home Screen > Add**.
4. Open it from the new **Restock** icon. It should open full screen, with no Safari address bar.

## 2. Offline test

1. With Wi-Fi on, open each department once (tap it, then go back).
2. Turn on **Airplane Mode**.
3. Close the app fully (swipe it away), then open it again from the icon.
   - [ ] The home screen opens and the top-right pill says **Offline**.
   - [ ] Each department opens.
   - [ ] Start a Quick Restock, enter a count for one product. The pill says **Offline · 1 saved on device**.
   - [ ] Product photos (if any) still show.
4. Turn Airplane Mode off.
   - [ ] Within a minute the pill says **All changes synced**.
   - [ ] In Admin > Restocks the quick restock is there.

## 3. Everyday use

- [ ] Buttons and number boxes are easy to tap with one hand.
- [ ] The number keypad appears when typing a count.
- [ ] Turning the iPad sideways and back keeps your place.
- [ ] Two devices on the same full restock: a count entered on one appears on the other after a few seconds.
- [ ] Finishing a full restock sends the manager email.

## 4. Admin on the iPad

- [ ] Hold the logo for 2 seconds: the admin sign-in opens.
- [ ] On a product, **Add photo** offers the camera. Take a photo: it appears on the product card for staff.
- [ ] **Sign out** before handing the iPad back to staff.

## If something's wrong

- **"This page hasn't been saved on this device yet"** while offline: connect to Wi-Fi, open the app and each department once, then try again.
- **The app looks out of date** after an update: close it fully and open it again while on Wi-Fi.
- **Changes stuck as "saved on device"**: check the Wi-Fi, then tap the pill to retry. Nothing is lost while it waits.
- **iOS storage**: Safari can clear saved website data for apps that aren't used for several weeks. Installing to the Home Screen (step 1) and using it regularly prevents this; restock entries not yet uploaded are kept until they upload.
